# Smart Campus Activity Booking System

A Java-based application developed to manage student registration for university campus activities.

## Features

- Register students for activities
- Unregister students from activities
- Prevent overbooking when an activity reaches its maximum capacity
- Display registered participants
- Provide a graphical user interface (GUI) for easier interaction

## Programming Paradigms

The system was implemented using three different programming paradigms:

- Procedural Programming
- Object-Oriented Programming (OOP)
- Event-Driven Programming

## Technologies Used

- Java
- Java Swing
- Eclipse IDE

## Project Structure

- `src/registration/` - Procedural implementation
- `src/oop/` - Object-Oriented implementation
- `src/eventdriven/` - Event-Driven GUI implementation

## Activities

The system currently supports:

- Digital Football Match
- Chess Competition

## Main Concepts Demonstrated

- Object-Oriented Programming
- Encapsulation
- Inheritance
- Polymorphism
- Event Handling
- Java Swing GUI
- ArrayList
- Input Validation
- Registration Capacity Management
